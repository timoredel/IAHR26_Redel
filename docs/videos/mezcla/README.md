# Casos adicionales: mezcla turbulenta

*Casos de referencia · inestabilidades y mezcla*

Dos flujos canónicos para estudiar cómo se mezclan los fluidos estratificados. En las interfaces entre agua dulce y agua salada de los proyectos anteriores actúan dos mecanismos: la mezcla por corte, en que la diferencia de velocidad entre capas genera inestabilidades que se rompen en turbulencia, y la mezcla por convección, en que la flotabilidad impulsa directamente el movimiento.

| Video | Descripción |
|---|---|
| [`RI03RE2525M2.mp4`](RI03RE2525M2.mp4) | Mezcla por corte: interfaz de densidad (Re = 2525, Ri = 0,3). Una capa liviana fluye sobre una más densa. El corte en la interfaz genera vórtices de Kelvin–Helmholtz que se enrollan, colapsan en turbulencia y mezclan las dos capas. El número de Richardson Ri mide la competencia entre la estratificación, que estabiliza, y el corte, que desestabiliza. |
| [`RB_PR1RA09.mp4`](RB_PR1RA09.mp4) | Mezcla por convección: celdas de Rayleigh–Bénard. Fluido calentado desde abajo y enfriado desde arriba. Las plumas térmicas que se desprenden de las paredes se organizan en celdas convectivas que mezclan el fluido. Se muestran la presión, las velocidades y la temperatura T. |
